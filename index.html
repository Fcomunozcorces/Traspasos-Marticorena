🚀 Cómo publicarla (GitHub + Netlify)
1
Sube el archivo a GitHub

Crea un repo nuevo (ej. oviedo-traspasos) o una carpeta dentro del repo del cotizador. Sube el index.html. No necesita nada más: la demanda ya va dentro.

2
Conéctalo a Netlify

Add new site → Import an existing project → GitHub, eliges el repo. Build command vacío y publish directory en la raíz (/).

3
Atajo sin GitHub

Entra a app.netlify.com/drop y arrastra el index.html. Queda publicado al instante.

4
Actualizar la demanda

Cuando quieras refrescar las ventas, se regenera el index.html con la venta diaria nueva y se reemplaza en el repo. Netlify redespliega solo.
